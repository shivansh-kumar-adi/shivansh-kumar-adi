### 🚀 Projects

| Project | Description |
|---|---|
| **[Datara](https://github.com/shivansh-kumar-adi/datara-showcase)** — Data Governance Portal | *Know your data. Govern with confidence.* Public showcase of Datara, a data governance platform I built. It covers architecture, data model, API, diagrams and design decisions, and it contains no source code |
| **[Automated ETL Pipeline](https://github.com/shivansh-kumar-adi/automated-etl-pipeline)** — Python Data Engineering | Production-style, backend-only Python ETL system that extracts public post data, validates and transforms every record, keeps the raw input for auditability, and does idempotent PostgreSQL UPSERTs. Includes deduplication, retry logic, run history, rejected-record details, a machine-readable reconciliation report and automated tests. Needs no paid services, API keys, Docker, Airflow, Kafka or cloud infrastructure |
| **[Distributed Consensus Simulator](https://github.com/shivansh-kumar-adi/raft-consensus-simulator)** — Raft in Java | Java simulator of distributed nodes demonstrating leader election, log replication, consensus and fault tolerance with a simplified Raft algorithm. Each node runs in its own thread over a simulated lossy network, survives crashes and network partitions, and saves state through a JDBC/SQLite layer. Includes a live Swing dashboard, a scripted demo and an automated test suite that continuously checks Raft's central safety property |
| **[TraceNut](https://github.com/shivansh-kumar-adi/tracenut---frontend)** — Warehouse Management | 🌾 *Raw material to dispatch, fully traceable.* Warehouse management portal built for Nutrithy Wellness: traceability and inventory for a makhana product line, with batches, lot codes, a warehouse registry, categorized destinations, scan-to-pack and a full accountability log |
| **[Little Lemon](https://github.com/shivansh-kumar-adi/little-lemon)** — Restaurant Ordering & Booking System | 🍋 Django REST backend for a restaurant: online food orders, paid table bookings with deposits, coupons, Razorpay payments with webhooks, and a sales report for the owner. Prices, tax and totals are calculated on the server. Runs on SQLite out of the box and switches to MySQL with one setting. 176 tests |
| **[Harmonie](https://github.com/shivansh-kumar-adi/Harmonie)** — WhatsApp Bot | Full-featured, self-hosted WhatsApp community bot built on Baileys. It connects the way WhatsApp Web does, with no Meta Business API or per-message fees. Has 47 commands, an AI assistant, an XP/badge/achievement system, daily quizzes, automated group analytics and moderation. Only an optional free-tier Gemini key is needed, for the AI features |
| **[Emotion Detector AI](https://github.com/shivansh-kumar-adi/Emotion-Detector-AI----From-scratch)** — ML From Scratch | Text emotion classifier (sadness, joy, love, anger, fear, surprise) with no API, pretrained model or ML library. TF-IDF, softmax regression with hand-derived gradients, and the Adam optimiser are all written by hand in NumPy. Trained on 16,000 tweets in about 22 seconds, served with plain Python and a 1.3 MB model file, and says "No strong emotion" when unsure. Flask + vanilla JS, deployable to Vercel |
| **[Hand Gesture Music Controller](https://github.com/shivansh-kumar-adi/Gesture-Media-Controller-Python)** — Computer Vision | Real-time, touchless media controller — hand gestures control play/pause, track skip, and volume via MediaPipe landmark detection and OpenCV, with cross-platform audio support (Windows/macOS/Linux) |
| **[Image Enhancement & Preprocessing](https://github.com/shivansh-kumar-adi/Image-enhancement-and-preprocessing)** — Computer Vision Pipeline | Built with Python, OpenCV & Streamlit. Upload an image, apply 12+ enhancement techniques (CLAHE, gamma correction, edge detection, HDR) and 5 preprocessing operations, tune parameters in real time, compare before/after and download the result |
| **[Community Referral Portal](https://github.com/shivansh-kumar-adi/Referral-Portel-for-companies-and-employees)** — Job Referral Directory | Full-stack web app where companies list themselves to offer referrals, and students or job seekers browse the directory and reach out directly. Built with Next.js 14, React 18 and Supabase (PostgreSQL) |
